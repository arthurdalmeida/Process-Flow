# Process-Flow

- O ProcessFlow é um programa que foi desenvolvido em C.

-Serve para cadastrar e executar tarefas.

-Utiliza processos do sistema Linux.

-Esse programa permite executar tarefas de maneira simples, paralela ou sequencial e oferece suporte a pipes, execução em background, alteração de diretório e pode ser utilizado tanto de maneira interativa quanto por workflow.

## Compilação

```bash
make clean
make

Execução


interativo: ./processflow
workflow: ./processflow teste.pf
